设计文件可以保存版面关系，同时继续引用外部图片。把文件发到另一台电脑后，原来的图片路径未必存在；交接前需要确认依赖文件是否一并准备，而不是只确认文件能在自己电脑上打开。

本文以Adobe的[InDesign输出打包说明](https://helpx.adobe.com/indesign/desktop/print/preflight/package-files-for-output.html)为操作参考，页面更新于2026年6月2日，查阅于2026年10月16日。其他软件的名称和选项可能不同，不能把这里的菜单步骤直接套用。

## 发出前，按这个顺序核对

1. 先解决预检中需要处理的缺失链接、缺失字体等问题。打包动作不能凭空找回已丢失的资源。
2. 检查是否需要复制链接图像，并核对打包中的链接更新选项。把资源放进交接文件夹后，要让交接版文件引用正确位置。
3. 按接收方要求决定是否附带IDML、打印PDF等文件；附带格式不等于已完成全部输出验证。
4. 在交接副本中重新核对链接和外观。不要只打开原工作目录里的文件，误以为测试了交接包。

## 用一张表说明交付内容

| 交付项 | 交接时写清什么 |
| --- | --- |
| 主设计文件 | 最终版本及应打开的文件名 |
| 链接图像 | 是否随包提供，有无待补文件 |
| 输出PDF | 用途及是否已完成双方要求的检查 |
| 字体处理 | 接收方是否具备所需字体和使用条件 |
| 说明文件 | 仍待确认的问题与联系人 |

Adobe说明中的字体复制存在例外，例如Adobe Fonts相关字体的处理不能简单理解成所有字体文件都会被复制。软件提供打包选项，也不等于自动获得字体再分发的许可；实际交付方式需要结合授权条件和接收方环境确认。

如果图片因保密或授权限制不能随包交付，应提前说明并约定替代交接办法，而不是让缺失链接悄悄留在最终文件中。接收方需要知道哪些内容是完整的、哪些内容还未到位，才能安排后续检查和制作。
